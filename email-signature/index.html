Install it once, forget about it

      

        

          
Gmail

          
    
            
  1. Hit Copy signature above.
    2. 
            
  2. Gmail → ⚙ Settings → See all settings.
    3. 
            
  3. Scroll to Signature → Create new, name it.
    4. 
            
  4. Click into the box and paste (Ctrl+V).
    5. 
            
  5. Set it as default for New emails and Replies.
    6. 
            
  6. Save Changes at the bottom.
    7. 
          

        

        

          
Outlook (web + new desktop)

          
    
            
  1. Hit Copy signature.
    2. 
            
  2. ⚙ → Mail → Compose and reply.
    3. 
            
  3. + New signature, paste into the editor.
    4. 
            
  4. Pick it under Select default signatures.
    5. 
            
  5. Save.
    6. 
          

        

        

          
Apple Mail

          
    
            
  1. Hit Copy signature.
    2. 
            
  2. Mail → Settings → Signatures.
    3. 
            
  3. + to add, then paste.
    4. 
            
  4. Untick Always match my default message font — otherwise it strips the styling.
    5. 
          

        

        

          
Anywhere else

          
    
            
  1. Use Copy HTML source for tools with a raw-HTML field (Zoho, Superhuman, HubSpot, Front).
    2. 
            
  2. Use Copy plain text for terminals, Slack, plain-text-only clients, and job boards.
    3. 
            
  3. Or open a file from raw/, select all, copy.
    4. 
          

        

      


      

        Two things that will save you an embarrassing email
        
    
          
  • After installing, send yourself one test email and open it on your phone. Mobile Gmail is where bad signatures fall apart.
    • 
          
  • On replies, don't stack signatures — Gmail inserts yours above the quoted thread, so a long one repeats down the chain. That's exactly why the Compact layout exists: full signature on first contact, compact for the back-and-forth.
